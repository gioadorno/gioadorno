### 🚀 **The FDE Arsenal**

Here are the specialized tools I've built for Forward Deployed Engineering:

| Tool | Core Tech | Description |
| :--- | :--- | :--- |
| 🧠 **[Nexus](https://github.com/gioadorno/nexus)** | Go, Python, Vertex AI | FDE AutoGen Orchestrator & CLI. Converts raw meeting notes into structured product specs, and autonomously scaffolds code across frontend and backend monorepos. |
| ⚡ **[Spectra](https://github.com/gioadorno/spectra)** | Go, BubbleTea | A blazing-fast CLI tool for parsing, profiling, and analyzing dirty datasets instantly before they break your ingestion pipelines. |
| 🪤 **[Snare](https://github.com/gioadorno/snare)** | Go, SQLite | A local "black hole" webhook interceptor. Captures chaotic webhooks from third-party systems for safe local replay. |
| 🌪️ **[Havoc](https://github.com/gioadorno/havoc)** | Python, Vertex AI | Hyper-realistic mock dataset generator equipped with a "Chaos Engine" to intentionally break and stress-test schemas. |
| 📚 **[Memex](https://github.com/gioadorno/memex)** | Python, ChromaDB | Background Obsidian vault RAG synthesizer. Automatically summarizes and links chaotic meeting notes to preserve context. |
| 🔍 **[Forge Lens](https://github.com/gioadorno/forge-lens)** | Python, Vertex AI | An AI-powered documentation engine that reads infrastructure code and writes professional Operations Runbooks automatically. |
